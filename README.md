# BEC PINN

This is a repository for the PINN that takes parameter space data for the double-targets and double-rings as posterior data and output CNN data and makes a final determination on whether or not transfer occurred for a particular measurement sequence of the double-target atomtronic rotation sensor. It also includes the sim_runner_toolkit Python library for running Rotating-frame Gross-Pitaevskii simulations under different configurations and parameters.
